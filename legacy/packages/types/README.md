# @oosc/types

Shared TypeScript domain models and type definitions for the OOSC Agent Reliability Engine.

## Contents

- **Agent Types**: `Agent`, `AgentIntegration`, `AgentStatus`
- **Scenario Types**: `Scenario`, `ScenarioCategory`, `ScenarioDifficulty`, `ToolStep`
- **Evaluation & Run Types**: `TestRun`, `TestResult`, `ExecutionTrace`, `TraceEvent`
- **Failure Taxonomy**: `Failure`, `FailureType`, `FailureSeverity`, `FailureStatus`
- **Reliability & Regression**: `ReliabilityOverview`, `RegressionResult`
